BEFORE YOU BEGIN

One safe setup step.

Open js/supabase-config.js and add your Supabase project URL and publishable key. Then run supabase/schema.sql in the Supabase SQL Editor.

Only use a publishable/anon key in the browser. Never expose a service-role key.

Privacy note: sync copies supported browser entries to your signed-in account. It does not delete local entries, and repeated sync can create duplicates.
