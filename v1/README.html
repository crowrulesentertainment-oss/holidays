Holiday Hub Starter

A static HTML, CSS, and JavaScript multi-page website foundation.

Included pages

Home dashboard, simulated Santa Tracker, Letters to Santa, holiday countdowns, holiday history and traditions, birthday list and greeting generator, tradition builder, memory board.

Run it locally

Extract the ZIP and open index.html. Or run python -m http.server 8000 from this folder and visit http://localhost:8000.

Limitations

  • Saved entries use browser localStorage; they do not sync across devices.
  • The radar is a simulation, not a live tracker.
  • Birthday greetings are generated in-browser; no email or SMS is sent.
  • The front end is not connected to Supabase/auth yet. See supabase/schema.sql for a starter schema that must be reviewed and integrated.
  • Remote images and fonts need internet. Replace with licensed local assets before commercial deployment.
  • Holiday list focuses on selected common US observances; dates and customs vary by region and tradition.

Recommended next steps

  1. Connect Supabase Auth and profiles.
  2. Move saved entries to database tables protected by Row Level Security.
  3. Add private Storage uploads for memory photos.
  4. Add an admin holiday editor and curated calendar source.
Never put a Supabase service-role key in browser JavaScript.
